This directory reviews all sixteen weighted-sampling margin fits and then freezes
their inference on the previously opened 384-game diagnostic. It requires the
exact 62-file fitting inventory, unchanged sources and memory readiness, matching
game and feature authorities, valid prediction arrays, and exact globals WDL reuse.

The fitting review retains every fold and all 60 slices in both distributions.
It compares point estimates with each architecture's original sampler and the
tree. These fitting differences are not paired change intervals.

After the fitting review is complete, the evaluator pins all models and reference
artifacts. Each model sees the same 288 fresh games from fitting families and 96
from excluded families. Paired cluster intervals compare margin errors with its
own original sampler and with the matching tree fold. Every paired point must
reproduce the difference between the reference and candidate MAEs. WDL remains
the exact matching globals prediction; it is not new classification evidence.

The completed diagnostic has 38 artifacts across the root, `numeric` and
`semantic` directories. The closeout review verifies the inventory, data/source
authority, WDL identity, all groups/slices and both paired comparisons. Empty
slices remain explicit. No acceptance or reserved-role changes follow from this
opened diagnostic, and sparse late coverage remains a limitation.

Use the shared Python environment with this directory, `hog26_weighted_margin`,
`hog26_terminal_auxiliary`, `hog26_semantic_margin`, `hog26_public_semantics`,
`hog26_residual_margin`, `hog26_scaling_review`, `hog26_scaling_eval`,
`hog26_seed_transfer`, `hog26_scaling_fit`, `hog26_data_scaling`,
`hog26_scalar_pilot`, `src` and the root on `PYTHONPATH`.

Run `review_fits.py` after all fitting completes. Then run `evaluate_weighted.py
--mode pin --fitting-review ... --pin ...`. Preserve every Python source after
pinning, run `supervise_evaluation.py`, and finish with `review_diagnostic.py`.
