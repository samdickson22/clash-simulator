## 5. Pitfalls

- **`pkill -f` matches its own pattern.** An `ssh host 'pkill -f "X"; …'` kills the ssh shell that contains "X". Use
  verified PIDs.
- **Re-check delegate conservatism.** The bring-up agent held the fleet fan-out on a defect that affected both
  platforms equally. The coordinator overrode it.
- **Disk-cleanup lesson.** Deleting `live-loop/l1/v3` also deleted the v3 model weights (now only on dead f35). Check
  folders for models or tracked files before deleting, even if a copy is supposedly verified.
