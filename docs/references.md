# Research references

Third-party papers are linked here instead of redistributed as PDF files in the repository.

- [Learning to Play Imperfect-Information Games by Imitating an Oracle Planner](https://arxiv.org/abs/2012.12186v1), arXiv:2012.12186v1. This is the oracle-planning and imitation reference discussed in the strategy council reports.
- [Playing Non-Embedded Card-Based Games with Reinforcement Learning](https://arxiv.org/abs/2504.04783v1), arXiv:2504.04783v1. This is the KataCR reference discussed in the external research review.

These replace `2012.12186v1.pdf`, `2504.04783v1.pdf`, and the duplicate `2504.04783v1 (1).pdf`. The links retain the referenced versions. See the [external review](../reports/external_review_20260928/) for comparisons and limitations.
