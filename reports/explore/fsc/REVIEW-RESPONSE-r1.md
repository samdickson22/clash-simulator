**Shadow scan (new, 03 only, read-only).** An allowlist copy could in principle drop an unpinned module that X4S2 actually
imported. So before copying, the scan lists only the top level of each runtime import directory in the source repo. It
refuses if an unpinned module or package there shares a name with a pinned or overlay module (`test_shadowscan`). Any
other missing file fails the smoke.

**Session pattern:**
- Each host gets one launch session, at most one progress session per 2 h (enforced by session.sh), and one stop session.
- 04's launch session also makes exactly two non-persistent read-only pulls from 03 (a dry run and the real copy).
- Each stop session makes one push to the 05 mirror.
