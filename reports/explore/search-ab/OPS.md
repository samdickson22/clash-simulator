The GPU guard reads only a configured job's fresh interval throughput. It compares a five-step harmonic mean to a separately measured baseline and pauses only below 95% of that baseline. Unknown/stale metrics and an absent GPU job are exempt. GPU utilization never triggers a pause. Cumulative throughput fields are rejected. A throughput baseline and log are required for guarded launches; never invent a baseline from utilization. The public shared helper is owned by the delay-fixes worker.

Workers run under SCHED_IDLE and taskset. Every two seconds the guard refreshes only its own process/thread affinities, excluding recently active GPU-job and feeder cores and their SMT siblings. The GPU processes' affinities remain untouched. The exclusion history is 30 seconds; this is periodic observation, not a reservation of the GPU process's full unrestricted affinity.

An atomic pause-clock JSON records completed and live pauses. New latency_seconds uses active wall time; raw_wall_latency_seconds and cpu_latency_seconds remain separate. With --pause-clock, optional decision-budget production and consumption use process CPU time. A CPU deadline is not a 200 ms wall-time guarantee. Shards count active time toward their limit, while the hard leased exit time remains absolute. Completed game files are resumable; incomplete games are rerun.
