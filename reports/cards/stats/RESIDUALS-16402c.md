## Exact worthwhile updates

**Void / DarkMagic: six existing raw fields.** Add explicit overlay slots connecting this gamedata prefix:

```text

```

to the 16.402 card record's:

```text

```

Map `damagePerSecond` to `damage_per_second` and `crownTowerDamagePerHit` to `crown_tower_damage_per_hit`; retain `hitFrequency = 100`. Match the laser action and tier names, rather than relying on a fixed action index in a general implementation. All six RS cells are explicit, so this does not relax the blank/uncertain rule. Merely adding a named-buff field mapping will not reach these source-less action blocks. The medium DPS is **1155 in 16.402.19**, not the older table's 1150. Keep the separate held Void elixir disagreement out of this update.

**Tornado: live pin selection only.** For the successor live runtime pin entry in `bot/players/runtime.py`, use:

```python

```

The existing hook then pops Tornado's crown override before resources build. No gamedata field needs changing. Keep historical pin sets unchanged; do not globally replace a shared measured override with another pin. Replacing the pin with 26 would still encode a level-specific exception; deriving from gamedata is the cleaner fix.
