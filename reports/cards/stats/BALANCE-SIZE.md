## (d) Notes and unsure fields

- Which copy is ours: the runtime copy `engine-cards/py/gamedata.json`, as the brief names it. The root `gamedata.json` (what statsdiff.py reads, the calibrated copy) differs from it on 12 fields in 11 spells (BarbLog, BarbarianHut, BarbarianLauncher, Barbarians, BattleRam, ElectroSpirit, FireSpirits, FirespiritHut, Goblinstein, Rascals, Wallbreakers). The STATSDIFF comparison used the root copy and so did not see those differences.
- Which build the runtime copy matches. Of the 44 material rows, ours equals the 16.402.2 value (`cards-160402017.json`) on 6, differs from it on 38, and is not comparable on 0; ours equals the 15.535.29 value on 18, differs on 26, not comparable on 0. A row counted as "equals" means the older file has no differing row for it.
- RoyaleSim versions: `cards-160402017-20261006.json` (16.402.19) is used. The older `cards-160402017.json` (16.402.2) differs from it on 29 card-level fields (BarbLog, Elixir Collector, Ghost, GoblinBarrel, GoldenKnight, LavaHound, MinionGiant, Monk, RamRider, Skeletons, SuperLavaHound, ThreeMusketeers, Wallbreakers, Xbow), so it is not the same truth.
- CLIENT16402_VALUES: 10 of 11 overlay values equal the 16.402.19 table as it stands; 1 not mapped. The overlay is already in the table, so applying it again changes nothing.
- Crown-tower damage: gamedata stores a negative delta (e.g. -75) and RoyaleSim an effective percent (25 or 23). We convert ours with 100 + raw for negative raw, per RoyaleSim's stated convention. Ours is the first crownTowerDamagePercent in the base card; a spell's own area or projectile, or a unit, counts as its own. Values in a buff, a spawn chain or a unit's own area effect are UNCERTAIN.
- Blank 16.402 crown cells: RoyaleSim loads a blank cell as 100 (raw None). Where ours is not 100 and RoyaleSim's only value is that blank, the row is UNCERTAIN, not a difference (Freeze, IceWizard, Zap). The 15.535.29 table has a measured value on those cards.
- Sub-units (death spawns, spawners, morphs, second units) are compared on base stats only, with the same rules as the card.
- The material list is the brief's (hp, damage, speed, range, hit speed, cost, spawn counts). Load time, sight range, deploy time, spawn interval and spell radius/duration are compared but not material.
- Nothing compares first-spawn timing or spawner radius (not in gamedata). Those are in (c).
