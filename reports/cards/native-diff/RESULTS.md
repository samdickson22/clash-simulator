**Cause notes and attribution limits.**

- **Ice Golem (IceGolemite) (75):** Pool uses IceGolemite; config exports its death area only when the requested alias is IceGolem. Rust death_effects consumes an absent death_areas entry. This is the known probe divergence, reproduced here with all-C56 decks as well.
- **Inferno Tower (8):** The native retarget-reset branch applies to Troop but skips non-ordinary Building. Python reset_attack_windup applies the building retarget delay. Mixed-game victims include C56 bodies and new-card bodies; C56-only status is not assumed without a reproduction.
- **X-Bow (5):** Public projectile birth is the first difference. The equal prefix already has a 50 ms hit-timeline offset; native creates a shot while Python still has 50 ms loading work. Some contexts include stun, and some a first acquisition; these are grouped by the observed clock failure, not asserted to be one proven source-code fix.
- **Boss Bandit × Mighty Miner / Monk (4):** Boss Bandit changes to travel in combat after another actor committed its movement target. Python revalidates that target in the movement component and stops; native spends the committed travel. Monk/Ice Spirit collision displacement also follows from this extra movement.
- **Electro Dragon (4):** Native checks the start-of-object-phase alive set before calling the hook. Python only notifies the source for a primary in the actual impact recipient set. The extra chain can damage a secondary or die immediately, leaving only a next_id difference.
- **Mega Knight (2):** Both weapon clocks fire on the same tick; leap phase is idle. Python exempts direct area damage and dashCooldown characters from its long-distance discard. Native applies the generic distance cancellation and drops the normal melee payload. This is not a jump-landing-damage discrepancy.
- **Mirror × Skeleton Barrel (2):** Mirror exports level12:SkeletonBalloon child templates, but bomb_tick looks up the unqualified stats.name. It selects ordinary level-11 children instead of the mirrored payload key.
- **Poison × Boss Bandit / Bandit (2):** area_targets omits the dash-travel effect guard before installing area slows and periodic buffs. In game 75 Python has no slow while native retains 0.85 movement; game 416 later receives a native-only 92-damage Poison tick (Bandit HP 286 / 194).
- **Ice Spirit × Boss Bandit; Heal collision (1):** The Ice Spirit path calls stun_target_mode with interrupt=false, but native still cancels the dash. Python preserves anticipation for this non-interrupting freeze. The latent state difference becomes public after thaw, also displacing the nearby Heal Spirit differently.
- **Valkyrie (1):** The moving Valkyrie has no ordinary clock in either adapter. Native has already preloaded to 0.1 s while Python is still reducing legacy cooldown; the native hit kills a Goblin before Python attacks. New units exist in the surrounding mixed game, so this is not silently labeled C56-only.
