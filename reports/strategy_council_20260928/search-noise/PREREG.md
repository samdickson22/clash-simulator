# Perception noise and C56 search strength

Registered before confirmation. Outcomes from development games do not enter estimates. There is no strength-based early stopping or retuning. All terminal confirmation receipts remain included. A fatal runtime defect stops the affected evaluation for a documented decision before resumption.

## Questions and schedule

Measure the strength cost when the Stage 5b deadline search player receives simulated perception errors. A, B, C and D each play 128 terminal games against A and 128 against C56 scripts, 1,024 primary games. Five repair ablations each play the same 128 script games, giving 1,664 total games. Scores are wins plus half draws divided by games.

Each stratum has 64 seeded matchups with two controller seats. Head-to-head keeps the world, decks, initial hands and engine seed fixed and swaps A and the tested controller. Script pairs put the family deck with the tested controller in both seats, swapping world seats. Every variant uses the same worlds, noise seeds and search RNGs. Families are Hog 2.6, Hog EQ/Firecracker/MM, Royal Hogs/Furnace, X-Bow, bait, Goblinstein, and AQ, with counts 10/9/9/9/9/9/9 per stratum. Script styles rotate balanced, pressure and defense. Human family decks are eval/eval_ood perspectives supported by the train-only prior. Opposing decks are train-frequency samples. This is role holdout, not unseen-deck evaluation.

schedule.json freezes decks, seeds, styles and ordering. seed-audit.json audits JSON/JSONL seed fields, NPZ metadata/seed arrays and textual occurrences throughout reports/, excluding this experiment. Pickled games are covered by their report/plan seed provenance, not unpickling arbitrary archives. Concurrent external jobs can create later artifacts; the audit is a launch-time snapshot. Development seeds are separate from all confirmation and noise seeds.

## Player and timing

The private runtime is a byte copy of the Stage 5b-compatible Python engine, unchanged C56 scripts/search, gamedata, and the qualified Stage 5b native binary. source-copies.json records origins and hashes. All experiment code and frozen runtime files are sealed before confirmation.

All conditions poll/capture at 10 Hz, starting at tick 90, with the existing planner's alternating search rule, hence nominal searches every 200 ms. This common cadence differs from Stage 5b's 250-ms polling/500-ms searching and is required for the requested live-loop cadence. A means clean inputs at this shared cadence, not an attempt to reproduce historical Stage 5b scores. The search budget remains 200 ms with two native workers, including sensor conversion, history assimilation and root reconstruction.

Noisy timing uses a three-tick image-availability lag, 150 ms, from 66.43 ms mean capture transport plus 49.59 ms median v3 inference, rounded up to the 50-ms engine tick. Polling rounds usable frames further to 100-ms boundaries. Commands arrive after max(100 ms, measured decision wall time), rounded up to engine ticks. One outstanding command per controller is permitted; the latest available frame is used after completion. The clock is exact and extrapolated using public elapsed time. A and latency_clean have zero sensor/action delay. Clean opponents retain zero artificial delay. Action latency and additive transport/inference are assumptions because concurrent capture/search/actuation was not measured. Both actions are chosen before fixed seat-order application. Delayed slot taps can be rejected or play a changed slot; these consequences are retained.

## Noise model

noise-model.json is frozen from L1 v1 and the v3 heldout continuous-stream predictions. The heldout noise statistics specify the experimental environment; they do not tune the player. A replay of frozen v3 event fusion reproduces 180/280 correct events and 270 predictions. No engine state is perturbed.

Board errors are independent per captured frame. Towers are retained, with Gaussian coordinate SD 0.015 tile. Non-tower recall is 94.11%, inferred from the v1 aggregate and tower counts; conditional coordinate SD is 0.11 tile, with a 0.38% tail uniform from 1.01 to 2.8 tiles. These reproduce about 93.75% non-tower and 96.95% all-entity within-one performance on the v1 mix. Phantom body count is Poisson with mean detected bodies times 0.078/0.922; identity/owner/features come from a perceived body, displaced with SD 1.5 tiles. A zero-non-tower board cannot generate a phantom from this kernel. Entity identities otherwise remain correct. These are an explicit independent-frame approximation, not measured temporal persistence. P16 body error rates are extrapolated to C56; the actual v1 body model does not cover the full C56 roster.

Non-tower HP has 66.06% coverage over all true non-tower entities. Conditional on a surviving detection, the readable probability is 0.6606/0.9411. Repairing board dropouts therefore also increases usable HP coverage. Readable bars have exponential absolute error with mean 0.0498 and a randomly selected feasible sign, bounded to [0.001,1]; the vanishing tail is capped at 0.49. Unreadable bars use a fixed 0.5 point estimate, never true HP. Existing scripts require point-valued inputs with confidence one, so the adapter labels the estimate as usable and counts imputations separately. Tower HP remains clean, since the reported HP error is for non-towers.

Own hand slot error is 0.31%, next-card error 0.08%, confused with another card from the publicly known own deck. Displayed elixir error probability is 2.92%; the error is plus/minus one or two, with conditional magnitude chosen for 0.035 unconditional MAE before bounds. True own cycle beyond the visible next card remains public bookkeeping as in Stage 5. Clock error is zero.

Opponent correct-event recall is 180/280 and precision is 180/270. Of eight proxy confusions, 8/280 events replace the true card with a wrong one. A proxy confusion is an unmatched same-side prediction within 500 ms and three tiles of an unmatched deployment; this is not a manually labelled confusion matrix. Remaining misses are dropped; independent Poisson insertions supply the remaining false positives with the measured false-positive card histogram. Insertions are deployment-proportional, an explicit assumption. Correct detections resample empirical timely event delays and x/y residuals, with quantized availability constrained to the 500-ms window. Conditional placement within one tile is 90%, yielding 57.86% across all true events. Rates pool both sides in the available study and are applied to opponent events here. Champion/resource-event recall uses the same rate because separate measurements are unavailable.

Noisy events alone update the frozen v3 OpponentPosterior, with 1,024 particles and its validation-selected event probabilities, missed-play rate and residual calibration. It never receives opponent truth. This avoids the exact Stage 5 tracker collapsing on contradictory events. Diagnostic elixir/hand truth is read only after action choice and cannot change beliefs, RNG or decisions. The noisy filter's simulated MAE and coverage will be reported; the study does not force them to equal the historical 2.1141 MAE. The v3 filter does not model champion resource events; these are counted. Clean-event conditions use the original exact C56 tracker and assert elixir/identified-hand parity.

## Conditions and attribution

A: clean public inputs. B: all measured noise and modelled latency. C: B with the entire derived opponent state replaced by a broad independent prior: uniform [0,10] elixir and a frequency-weighted train deck with shuffled hand/cycle. D: B with 90% correct-event recall and precision, proportionately fewer proxy confusions; event positions and delays, and the frozen opponent filter/calibration, stay unchanged.

board_clean, hp_clean, hud_clean, events_clean and latency_clean each repair the named channel in B, leaving all others noisy. events_clean replaces noisy-event filtering with exact public-event derivation; its effect includes that practical inference change. Repair cost is score(repair) minus score(B), paired by matchup. These conditional effects need not sum because sources interact. The two primary mechanisms within derived-state quality are also compared with C minus B and D minus B.

Event placement coordinates do not enter the current search player's opponent filter or root reconstruction. An invariance test must establish that changing only those coordinates leaves actions unchanged. Their direct cost is structurally zero for this adapter, not evidence that placement is irrelevant to a real vision tracker.

## Analysis and recommendation

Use 10,000 percentile bootstrap samples of the 64 paired-matchup means, keeping both seats together. Bootstrap seed is 3905100043. Report 95% intervals for scores and paired score differences. Family scores, especially Hog 2.6, are descriptive. No unpaired binomial interval replaces matchup bootstrapping.

A provisional simulator strength gate requires B versus A point score >=0.45 and lower 95% bound >0.40, and B script score within five percentage points of A with the lower bound of B minus A above -0.10. Passing supports a guarded simulator/offline closed-loop pilot only. It cannot certify full C56 detection, lifecycle, frame timing or official-client use. Rank sources by conditional script-score repair, with overlapping intervals treated as unresolved. Store no images, roots or per-tick battle dumps. Keep outputs below 300 MB and at most three owned nice-10 heavy processes.
