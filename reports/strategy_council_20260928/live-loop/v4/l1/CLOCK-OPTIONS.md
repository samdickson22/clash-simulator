## Frozen requirement and consequences

PREREG, Replay and endpoints: “Availability is output completion, including FIFO backlog, not frame capture or backdated execution time.” The registered primary endpoint is Mac replay with the emulator idle-running. Fleet replay remains diagnostic and cannot satisfy the Mac latency gate.

A uses fresh standalone measured service and the registered FIFO recurrence. This repairs implementation while preserving that availability definition. B substitutes estimated availability and therefore changes the evaluation measurement. It needs a dated prospective amendment and independent review **before selection**, not just a transport/optimization receipt. The original L1 verdict cannot be described as measured under the original protocol if it uses B; publish the amendment and distinguish modeled-time results. Mac E4 still requires genuine measurement separately.

The proposed formula production + modeled service alone drops accumulated backlog. A coherent service-time model must instead use `available_hat[i] = max(production[i], available_hat[i-1]) + service_hat[i]`. Alternatively a model of total lag, explicitly including backlog, could be added to production; it must not be called per-frame service. No division by nine, copied reference clocks or inferred startup offsets is admitted.

## B: sampling and deterministic timing model — proposed review brief

One prospective design for review: all24 epochs × all9 body branches ×8 fixed calibration matches; another8 disjoint validation matches are held back only from timing-model fitting. These are **validation** matches, never the frozen heldout evaluation split. Choose both lists before measuring by deterministic hash within four strata of validation receipt event density, with two calibration and two timing-test matches per stratum. Freeze hash seed, tie/order rules, exact identities and all public frame times. Every late epoch15–24 is included; no dropping cold starts, slow matches or failed predictions. Use whole matches. This proposal does not itself freeze or execute the sample.

Calibration alone costs1,728 match-branch passes,12.5% of A by match count. With eight independent timing-test matches it costs3,456 passes,25% of A. Actual frame-weighted cost depends on the frozen lists; do not assume exact25% for unequal lengths. Any event-threshold-specific timing calibration and final configuration validation add cost. Model implementation, independent review and CPU application/equality checks are additional, unmeasured work.

Freeze model family/features/loss before fitting. Separate cold first-frame and block-fetch terms; preserve branch/epoch workload variation without using event correctness or heldout outcomes as predictors. A prediction of service must propagate its own FIFO state. Do not silently winsorize measured startup or I/O stalls. Describe hardware, co-located work, host/cache effects and limits on transfer to Mac.

Report epoch/branch/density strata and cold/cache-boundary frames. Freeze acceptance thresholds before test results; a failed test is a failed candidate, not permission to tune on that set. A different model after failure needs a new reviewed validation design. No accuracy result or expected timing error is presently measured.
