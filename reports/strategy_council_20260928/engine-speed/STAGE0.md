# Stage 0 results

2026-10-03. Python remains the default engine and the byte-identity reference.
The recorded gate passes on the fixed three-run SRP comparison. Host CPU timing
varies substantially; the initial pair alone did not reach 1.5x.

## Changes

- P1 replaces spawn-water checks with an immutable lookup.
- P2 overlays building costs without copying the arena cost map.
- P3 tracks A* heap positions while retaining the original tie order.
- P4 caches occupied-cell sets with a bounded LRU. Tuple normalization preserves
  mutable occupancy fixtures and avoids allocating for existing tuple snapshots.
- P5 rejects plane, building-only and sight mismatches before expensive validity checks.
- The opt-in `clasher.rl.script_rollout_planner` uses actor-only observations and
  skips observations only when a P16/v4 hand is provably unaffordable, preserving
  float32 mask boundaries. Existing learner and frozen OQ entrypoints are unchanged.
- `build_cython.py` compiles twelve modules in an external source snapshot. It moves
  the unchanged Numba helper into an uncompiled snapshot module. Disabling Cython's
  annotation inference preserves Python's acceptance of subclasses such as defaultdict.

The exact engine delta is `stage0_engine.patch`, relative to the saved pre-edit
source, not Git HEAD. `results/stage0_engine_sources.json` records its hashes.

## Identity and regression evidence

Every P1-P5 edit passed both identity checks, including P4 and P5 after recovery.
Each check covered 12 P16 episodes / 15,949 boundaries and seven C56 episodes /
2,900 boundaries, with zero mismatches. The corrected Cython build passed both too.
The P16 digest covers full state and observation packets; the C56 harness also
compares branch traces and deployment acceptance.

Both final Python and corrected Cython passed 189 tests, including
`tests/test_scope_engine_cards.py`, the touched engine suites in
`stage0_engine_tests.txt`, and both script suites. The initial typed Cython build
passed identity but failed 46 fast-path cases on exact-dict inference. Those
failed-build logs remain under `logs/*_typed.log`; they are not final receipts.

All engine benchmark match digests and all recorded SRP root actions, continuation
actions, leaf scores/digests and rollout tick counts match. The independent script
audit checked 6,702 continuation actions; the shortcut skipped 5,152 observations
in each 12-call fast run. SRP snapshots SHA256:
`182669bbd75a81e653afdd2785353a8294adcaa6684f2563e5d933e2e9aec945`.

## Measurements

Engine benchmark: four matches after two warmups, 17,548 measured ticks, same
seeds/decks. Instructions count the complete identical benchmark process,
including warmup and the action harness; ticks/core-s time only engine stepping.

| Variant | Engine ticks/core-s | Tick speedup | Process instructions | Reduction factor | Initial SRP core-s/call |
|---|---:|---:|---:|---:|---:|
| Saved Python reference | 566.412 | 1.000x | 526.603 billion | 1.000x | 2.828744 |
| Python P1-P5 + fast script | 667.644 | 1.179x | 475.979 billion | 1.106x | 2.469441 |
| Cython P1-P5 + fast script | 944.782 | 1.668x | 337.605 billion | 1.560x | 2.145887 |

The initial SRP comparison gives 1.145x for Python and 1.318x for Cython. A second
baseline differed by 19.6%, so a fixed three-run comparison was specified before
seeing the compiled result. Each run executes the same twelve recorded calls.

| Run | Reference core-s/call | Cython fast core-s/call |
|---|---:|---:|
| 1 | 2.828744 | 2.145887 |
| 2 | 3.382813 | 2.073853 |
| 3 | 4.528922 | 1.910693 |
| Mean | 3.580160 | 2.043478 |

The aggregate reduction is **1.752x** over 36 calls per variant. These are serial
process-CPU measurements on a shared P/E-core host, not a stable isolated-machine
speed guarantee. The initial pair failed the threshold, and the individual values
must accompany the mean. Every repeated run had identical complete action/leaf traces.

Gate results: zero digest/action differences, 189 green regressions, 1.560x fewer
engine-workload instructions against the 1.4x target, and 1.752x aggregate SRP
against the 1.5x target. **Admit the Stage 1 experiment.** Pure Python alone does
not meet the performance gate.

## Reproduction and scope

`results/stage0_summary.json` is generated by `summarize_stage0.py`; raw results
and `/usr/bin/time -l` logs are retained. `run_stage0_srp_repeat.sh` records the
fixed repeat schedule. Do not replay `run_stage0_python.sh`; it now refuses to
overwrite the baseline or reverse patches after P1 has started.

The tested optional build is at
`~/.cache/clasher-engine-speed/stage0-cython/src`. Select it only with an explicit
`PYTHONPATH`; ordinary checkout imports still resolve to `.py` files.
`results/stage0_cython_build.json` records compiler settings, source and binary
hashes. No frozen runtime, learner or external-job source was edited.
