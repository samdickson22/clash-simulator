## 6. Pitfalls learned the hard way

- **T3 restarts cancel delegated agents; a full app restart also killed `setsid` jobs.** Make every job resumable from disk, and after any restart check `ps` for every job.
- **The gamedata drift slipped past a narrow identity check.** Use all four identity modes (scripted, recorded srp games, random placements, C56).
- **macOS `find -size -1M` matches only empty files.** Use `-1024k`.
- **Never stage a whole `reports/` tree.** It holds copied `src/` trees and runtimes; commit docs and analysis scripts only (no files >5 MB, no binaries).
- **Pre-register before games.** Fresh seeds, pass bars and the analysis fixed in advance; report every result. Independently re-verify delegated claims, e.g. unseen parity cases or recorded-game replays.
- **Disk:** the Mac mini runs at 95–99% because other projects (roader, colima) use most of it.
- **Private-server reference:** the offline native validation reference is a re-signed private-server client (Null's Royale) with an injected probe, used offline only. That's a ToS/IP risk flagged to Sam; never network it and never commit it.
